# P3-V0 通用粒子层:刀光拖尾与格挡火花

## 1. 内容
- `client/vfx/`:`ParticlePool`(定长数组、满了环形覆盖、生成与更新不分配对象)、`Curve`(16 格预采样)、`EffectDef`(数据与校验)、`EffectLibrary`(加载;坏效果跳过并报告,缺文件则回退原版粒子)、`Vfx`(池、事件订阅、世界之后的一次无贴图绘制)、`BladeTrails`(刀光采样与带状绘制)。
- 数据:`assets/clashweave/vfx/effects.json`(`guard_block`、`guard_parry`、`blade_trail`)、`bindings.json`(`BLOCK`/`PARRY` → 效果)。不在 `content/` 下,不进规则哈希。
- 接线:`WeaponRendering.blade()` 上报刀的位置(第三人称;第一人称手臂与菜单里的玩家模型不上报)、`ClientProxy.initialize()` 注册、`DefaultPresentation.clash()` 查表放效果(无绑定或 `-Dcw.vfx.off=true` 时沿用原版火花)。
- 刀光:每帧把刀刃两端从眼空间换算为世界坐标,保留 ~0.3 秒;只有刀刃相对持有者的速度超过 3 方块/秒才出现、9 方块/秒时全亮,所以持刀静止或走路不出光。

## 2. 实机验证(0 ms,均为真实客户端截图,`docs/p3/v0-shots/`)
| 运行 | 内容 | 结果 |
|---|---|---|
| p3-v90b / p3-c0 / p3-c150 | 轻击连段 + 居合,自由相机 90°/0°/150° | 刀光贴着刀刃、随挥砍生长、约 0.3 秒内消失 |
| p3-f-guard_parry / p3-f-guard_block | 在固定点放效果,每刻一帧 | 精准:火花 + 闪光盘 + 扩散环;普通:较小的火花束 |
| p3-final-guard | 真实格挡对僵尸(`--guard`) | 精准格挡在接触点出现火花、闪光与环 |

## 3. 过程中的缺陷(记录保留)
- **平直着色**:世界渲染之后 GL 处于平直着色,多边形只取最后一个顶点的颜色。表现为火花尾、闪光边缘(透明度 0)整块消失,只剩环的外缘;刀光只显示成一片淡蓝(之前一轮 p3-v90 的"太淡")。修法:绘制阶段显式 `glShadeModel(GL_SMOOTH)` 并随属性栈还原。诊断过程用过 p3-guard2/3/4、p3-b-*、p3-s-*、p3-solid(全红实心,确认几何与位置无误),这些运行均保留。
- **公告板方向**:最初用 `ActiveRenderInfo`,它按玩家自己的视角计算,夹具用独立相机时圆盘侧着看成一条线。改为取视图矩阵旋转的各行(相机的右、上、前),与持有相机的实体无关。
- 叠加混合在亮色天空上几乎看不见,火花与闪光改为普通透明混合,刀光仍用叠加。
- 夹具:僵尸在日光下一直燃烧遮挡画面(现在追击靶设免火);放置高度曾取玩家的眼高,圈悬在头顶。

## 4. 未验证 / 限制
- **100 ms 延迟**未跑:特效纯客户端,不依赖往返,但按口径应记为未验证。
- **第一人称**自己的刀不出刀光(手臂用另一套投影)。
- 其他事件(崩势、落斩、延迟斩、影缝、切上、模式)仍是原版粒子;怪物未接入——属 V2/V3。
- 低帧率下刀光按帧采样会出现棱角;未专门测。
- 刀光在战斗中的颜色/强度、火花数量都是起始值,等你的手感意见调整。
- 加载只读类路径资源,**不支持资源重载热更新**(与计划里的 F3+T 不同);需重启客户端。
- 数量上限 512 粒子、16 个刀光槽、每槽 48 个采样;满了环形覆盖。未做距离裁剪。
- 性能未测(口径:不跑 A/B)。
