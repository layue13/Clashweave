# P2-c 精准格挡后的反击

状态:已合并进 `work`。数值是起点,未验证为最终值。

## 1 做了什么

- **入口规则**:`EntryRules` 新增可选的 `counter` 表(输入 → 动作),`style.json` 里 `"counter": { "LIGHT": "katana:counter" }`;`Scheduler.buffer` 在反击窗口(`counterWindow`)内、空闲时,按这张表起动作,窗口外轻击仍是原来的轻击。反击规则进入 `toWireJson`,所以客户端与服务端的内容哈希一致;`ContentRegistry` 校验 `counter` 里的动作必须在风格图里。
- **动作 `katana:counter`**:启动 3、有效 2、恢复 8,伤害 4,射程 2.5,弧 100°,架势伤害 30(能很快把目标打崩势),可接 `light_2`(命中取消窗口 [5,9))。轨迹由 `motion2.py` 生成(快速的横向反斩),已重新生成。
- 先前的占位逻辑(反击窗口内轻击只释放防御)保留作为入口:按住防御时轻击先释放防御再进反击。

## 2 验证

- 单元:`CounterTest`(窗口内起反击、窗口过后恢复原动作、反击规则进入哈希),总数全过。
- 实机(`p2c-1`,`--guard --jvm-arg=-Dcw.p2.counterAt=6`:玩家真实按住防御,服务端在按下后第 3 刻打出精准打击,客户端在按下后第 6 刻按轻击):8 次精准格挡 → **8 次 `katana:counter` 起动**(`CW START`);反击全部命中;反击的架势伤害使僵尸崩势 3 次(`BREAK` 事件)。画面里反击是从防御姿态直接刺出的一击,配火花。
