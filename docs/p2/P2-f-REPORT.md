# P2-f 气与模式循环 报告

## 1. 范围
`core/Gauge`(积攒、限频、满槽激活、模式内暂停积攒)、`Intent.MODE`、`StateMessage.gauge/mode`、HUD 文本行、模式内居合延迟斩增强(间隔减半、追加一段、第二段 ×0.6)。

## 2. 默认参数(全部未经手感验证,见 `CombatConfig` 的 gauge 组)
| 项 | 值 |
|---|---|
| 上限 | 100 |
| 命中(每次挥击一次) | 6,连击加成 +1/级,上限 4 级,间隔 ≤30 刻保持连击 |
| 普通格挡 / 精准格挡 / 受伤 | 4 / 8 / 5 |
| 格挡、受伤最短间隔 | 8 / 20 刻 |
| 模式时长 | 300 刻(实机夹具用 `-Dcw.p2.modeTicks` 覆盖) |

## 3. 实机结果
| 运行 | 条件 | 结果 |
|---|---|---|
| p2f-1 | 0 ms,模式 200 刻 | 空槽按模式键 `REJECT:MODE_NOT_READY`;真实挥击与受伤把槽积到 100;`MODE` 被接受,槽清零,模式内槽保持 0;模式结束后居合为单段(`mode=false`)。**模式内居合未覆盖**(夹具等待过长,模式已结束)——夹具问题,已修。 |
| p2f-2 | 0 ms,模式 500 刻 | 模式内三次居合各调度两段延迟斩(`mode=true`),间隔 3 刻,第二段伤害 1.8 = 3.0×0.6。 |
| p2f-3 | 100 ms,模式 500 刻 | 同 p2f-2:空槽拒绝、满槽 `MODE`、模式内三次居合各两段(间隔 3 刻,第二段 1.8);模式外居合单段。 |

## 4. 失败 / 未验证
- 模式内每次居合的两段里**总有一段 `hit=false`**(0 ms:第一段 3/3 未中;100 ms:第一段 2/3 未中、第二段 1/3 未中):延迟斩在目标原位置扫击,目标被击退/追击移动后离位。每次居合至少一段命中(6/6),但未查清是否为夹具特有,未改。
- 模式内 `DELAYED_SCHEDULE` 之外的模式增强(踏步闪移)**未做**。
- HUD 只有文本行 "Gauge N% MODE Ns";观察者看不到模式表现(无刀身微光/脚下环);模式结束无专门表现。
- 持久化规则只做"死亡清空";换维度保留未验证。
- `Intent.SPECIAL`(主动 SA)仍是占位。
- 所有数值未经手感验证;性能按既定口径不测。
