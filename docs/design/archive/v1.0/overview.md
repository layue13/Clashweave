# 第一部分：项目定位与设计目标

## 1.1 项目概述

Clashweave 旨在为 **Minecraft 1.7.10** 构建全新的、独立于 SlashBlade 的动作战斗框架，不依赖 SlashBlade，也不需要兼容原有拔刀剑 API 或附属刀剑。第一套内容选用打刀及日式剑术；引擎本身应能支持未来的长枪、大剑、双刀、拳术和其他战斗风格。

设计参考并非直接复刻，而是吸收各作品的机制特点：

| 参考作品 | 借鉴思想 | 在本项目中的使用方式 |
|---|---|---|
| SlashBlade | 拔刀、高速连斩、空中追击 | 打刀内容层的动作风格 |
| Devil May Cry | 连段派生、动作取消、视觉华丽性 | 多入口动作图和追击选择 |
| Sekiro | 姿态压制、攻防节奏、精准反击 | 防御与崩势机制 |
| The King of Fighters | 资源驱动的连招取消与爆发 | 进攻 Burst |
| 死神 VS 火影 | 受击脱困、战斗节奏转折 | 防御 Burst |
| Guilty Gear | 进攻资源与脱困资源之间的取舍 | 共享 Burst 资源池 |

**定位不是将 Minecraft 改造成纯格斗竞技场。** 探索、挖掘、方块交互、生存和多人合作应继续自然运行。

## 1.2 产品与引擎分层

```text
Clashweave
├── Combat Framework
│   ├── 输入意图、输入缓冲与动作选择
│   ├── 动作图、分层状态与时间轴
│   ├── 防御、崩势、位移、命中和伤害
│   ├── SA、Burst、资源与连招预算
│   └── 多人网络同步及权威判定
├── Presentation Framework
│   ├── 第一人称武器和手部动画
│   ├── 第三人称全身动画
│   ├── 相机与目标辅助
│   ├── HUD、音效、刀光和命中反馈
│   └── 动画资源管线
├── Combat AI
│   ├── 感知、距离与局势评估
│   ├── 战术决策和虚拟输入
│   └── 可调整的反应能力
└── Combat Content
    ├── 第一套打刀 Combat Style
    ├── 招式、SA、Burst Profile
    └── 后续武器、流派和附属内容包
```

Combat Framework 决定规则；Presentation Framework 决定玩家看到与听到什么；Combat Content 决定一类武器如何使用框架能力。三者不能互相形成隐藏依赖。

## 1.3 六条不可妥协的原则

1. **简单操作、复杂决策。** 普通玩家能用轻攻击、重攻击、格挡、闪避完成战斗；高手依靠时机、间合、资源及连招路线取得优势。
2. **玩家保有控制权。** 输入缓冲和取消应让操作更顺手，不能让角色在玩家停手后继续执行一串过期指令。
3. **进攻、防御、移动都有明确价值。** 禁止无脑连点、无限格挡、无限浮空形成压倒性最优策略。
4. **SA、Burst 是改变局势的工具，不是替代基础战斗的伤害按钮。**
5. **双视角共享单一权威战斗结果。** 切换 F5 不改变命中、范围、时间窗口、伤害、资源或角色坐标。
6. **框架提供能力，不要求每把武器使用全部能力。** 长枪不一定有纳刀；格斗风格不一定有架势条；某些风格可以不支持 SA。

# 第二部分：实际战斗体验与交战循环

## 2.1 战斗循环

```text
观察 / 接近 → 试探 / 交锋 → 争夺先机
                                  │
                   ┌──────────────┴──────────────┐
                   ▼                             ▼
              创造对手破绽                   失去主动权
                   │                             │
              连招 / SA                     格挡 / 踏步
                   │                         / 防御爆气
                   └──────────────┬──────────────┘
                                  ▼
                            重整 / 纳刀
                                  │
                             再次交锋
```

交战节奏包含三个可重叠层次：**基础交锋**（攻防、距离与时机）、**高速追击**（崩势、浮空、取消）、**爆发重整**（SA、爆气、恢复）。它们不是强制的四阶段状态机；玩家可以在未崩势时连击，也可以提前收刀结束追击。

## 2.2 普通 Minecraft 实体的兼容层级

| 等级 | 适用对象 | 能力范围 |
|---|---|---|
| Tier 0 | 原版普通实体和多数模组实体 | 接受新攻击、伤害、击退及必要的受击反馈 |
| Tier 1 | 强化战斗实体 | 有硬直、崩势、抗浮空与部分防御行为 |
| Tier 2 | 玩家、专用剑术敌人、Boss | 使用完整动作图、攻防、SA、Burst 与资源决策 |

玩家不应为了使用刀而必须将全部原版怪物替换成特殊 AI。普通生存仍然能够正常进行。
