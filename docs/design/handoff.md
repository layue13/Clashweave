# Clashweave 当前设计交接

更新日期：2026-10-09。本页恢复当前审核与原型上下文，原交接见[历史资料](archive/v1.0/handoff.md)。

## 当前任务与项目状态

用户要求完善资料后 commit/push，亲自审核，再委派原型。当前批次只提交现有 Forge 骨架和设计资料，不启动原型。先读[审核入口](review.md)、[设计状态](design-status.md)和[原型说明](proposals/prototype-spec-v1.md)。

独立 Minecraft 1.7.10 / Forge 10.13.4.1614 框架，项目名/mod ID 为 Clashweave/clashweave。首套内容是日本刀与居合，后续扩展不同武器。最初来源为[分享讨论](https://chatgpt.com/share/6ac81533-4cd0-83e8-86d8-fad07e0491c5)。原稿 22 章和 76 个编号小节/里程碑的保留说明见[审计](reviews/baseline-retention.md)。

只有初始化骨架。既有构建检查证明工具链，不证明客户端/服务端实际运行、战斗、动画或网络已实现。Java 8 为目标，Gradle 运行 Java 25、反编译工具 Java 17，环境说明见[根 README](../../README.md)。

## 已接受的实施基线

用户接受[综合方案](proposals/combat-recommendation-v1.md)作为原型基线：

- 保留纳刀/居合、轻重、切上、有限空中追击与完整收束。简化输入不删除战术选择，纳刀以准备成本换居合的间合/时机机会。
- 同类武器主体剑术相近，SA 添加效果和主动独立/连招/反击/空中/终结变体，不缩成纯被动或单一外部技能。
- 首轮一条模式槽，攻击/有效格挡/受伤参与积攒，常态 SA 不统一付气。合法激活后模式内暂停下一次资格积攒，先保留已经积攒的气、不做脱战衰减。
- 普通格挡、精准反击、踏步与有限控制无气也成立。崩势是机会，SA/爆气不能重置控制保护。
- 第一/第三人称规则一致，锁敌有界对准，鼠标观察优先，弱跟随与可选自动第三人称，F5 不重启动作。
- 动作请求共用 Scheduler/ActionRuntime，规则与表现分离、服务端权威，架构接口尚未实现或冻结。

次元类能力可作样例，延迟空间斩与指定踏步闪移需验证；强形态不要求所有 SA 都有。旧固定键表、单 SA 槽和三类自动 Burst 不作为当前限制。未明确修改的原稿继续继承，后置能力不是删除。

## 本次补齐的审核候选

比较布局为左键轻、右键重、Shift 防御、Alt 回避、中键锁敌、R 纳刀、B 模式。原型说明新增 V 通用主动特殊和 F 临时原版交互切换；它们尚待本次审核。移动中主动 SA/纳刀、Shift 疲劳、Alt/空格衔接和原版潜行/开箱必须实测，侧键可选且不作为硬件前提。

持刀默认战斗，纳刀与未锁敌仍适用；交互切换是显式临时状态，不能在承诺/恢复中绕过成本。GUI/换物品清理旧输入，不重新生成精准按下、不重复命中。

模型/动作推荐用 Blender。刀/鞘是挂在手/腰的刚性几何，角色骨架负责腰胸/肩臂扭转。静态几何/纹理、动画/挂点、权威轨迹分别导出。部位遮罩/全身覆盖与观察修正明确，皮肤/盔甲需适配；原版单块躯干不能证明正式分段扭转效果。详见[模型资源](modules/assets.md)。

## 审核后原型交付

[原型说明](proposals/prototype-spec-v1.md)拆分 P0 数据/运行时、P1 资产/输入/双人同步、P2 完整交锋。先以占位刀接通输入→权威动作→命中→双视角反馈，再验证原稿完整路线、防御/控制、SA 与模式循环。高级 IK、全部形态和正式美术可后置，总体规划保留。

测试值沿原稿起步，缺少的参数要在配置与交付报告中明示；禁止零恢复缺省、过期派生偷换招、模式无限自续和碰墙穿越。专用服务器不能加载客户端模型/渲染类，双人同步应早期验证。

执行者提交参数、构建/游戏内复现记录、人体工学和控制时长/模式机会测量，不以骨架 build 或一条特效演示替代验收。具体默认键、最终数值、装配互斥和 API 仍待验证；未经用户本批审核，不启动委派。
