# 防御、架势与控制链

> 整理日期：2026-10-08。当前讨论入口；已确认方向与提案分别标明，尚未实现或验证。
> 状态总表：[设计状态](../design-status.md)。原稿章节：[V1.0 设计对照](../archive/v1.0/defense.md)。

## 模块职责

管理防御、受击、架势与控制保护，决定攻击流中的反击机会。用户明确要求格挡和受伤也参与爆气积攒；资源规则由[Burst 模块](burst.md)维护，本模块提供已确认的交锋结果。

## 继承提案

| 结果 | 设计意图 |
| --- | --- |
| 普通格挡 | 以方向、风险与有限承压换取减伤 |
| 精准格挡 | 以准确时机换取较好恢复与明确反击窗口 |
| 防御失败 | 按正常命中处理，给可理解反馈 |

按下和持续防御是不同事件，重复点按不能无成本刷新精准窗口。具体物理输入尚未决定；旧右键、3 tick 与 140° 仅为历史参数。

架势稳定度可用于首套日本刀风格，耗尽创造短暂破绽；普通生命伤害不依赖先打空架势。该机制不强制适用于每种武器或实体。

## 控制保护

首套内容保留[切上挑飞与空中追击](katana.md)。具体开放机会尚待定义，不默认每次重击都挑飞；崩势或合法命中派生属于候选，需要与预算和保护共同验证。

连续硬直和浮空必须有边界。原稿提出控制预算、抗浮空与伤害衰减；具体算法与时长尚未确认。SA、换目标、换武器和模式进入不能随意重置受击目标的保护。

没有爆气时也应能重新获得基本行动机会。独立防御脱困是否保留，是待研究的能力，不默认继承旧防御 Burst。

## 本轮攻防起点（已接受为原型基线，待验证）

建议普通格挡消耗架势，精准格挡争取明确反击窗口；踏步测试短促且声明起止的防护窗口，准备/恢复可受击，暂不新加通用体力槽。切上/空中追击先用原稿控制预算和抗浮空起步，模式与 SA 不重置保护，无气也能重新获得行动。具体收益与取消仍逐动作声明。完整路线与风险见[综合推荐](../proposals/combat-recommendation-v1.md)。

## 待解决

反击窗口能到达哪些普通/SA 节点；格挡漏伤的资源结算；不可格挡攻击的反馈；多攻击者共享保护；预算归属、恢复条件、PvE/PvP 差异和同 tick 攻防顺序。

验收需要同时覆盖持久防御、反复精准格挡、多人围攻与无资源受压，检查是否出现唯一最优防守或无限控制。

## 第五部分：攻防、间合与崩势

### 5.1 三种防御结果

| 结果 | 条件 | 效果 |
|---|---|---|
| 普通格挡 | 正确方向、非精准时间窗 | 降低伤害、消耗架势、存在格挡硬直 |
| 精准格挡 | 接触时处于短暂精准窗口 | 减少架势损失、缩短硬直、开放反击 |
| 防御失败 | 方向错误、不可防御或窗口外 | 正常受击 |

按下防御输入进入防御，初始前 **3 tick** 为精准格挡窗口；继续按住是普通格挡，松开退出。重复点按不能无限刷新精准窗口，需要再防御限制与明确的硬直规则。

第一版以**正面约 140° 扇区**作为普通格挡测试参数。精准格挡主要赢得动作帧优势，不必直接把对方打崩势；更复杂的方向性防御留给后续武器风格。

### 5.2 间合与攻击路径

攻击命中应考虑距离、朝向、实际刀刃轨迹与角色位移，不能单纯使用“半径四格内全部命中”。横斩适合近中距离扇形攻击，突刺更长但更窄。第一版优先通过不同的真实轨迹形成距离差异，而非大量隐含伤害倍率。

### 5.3 架势稳定度

`Posture Stability ∈ [0,100]`：100 稳定，0 崩势。

| 事件 | 稳定度示例变化 |
|---|---:|
| 普通攻击被格挡 | 防守方 -8 |
| 重击被格挡 | 防守方 -20 |
| 精准格挡 | 防守方 -2 |
| 普通攻击直接命中 | 目标 -12 |
| 重击直接命中 | 目标 -22 |
| 脱离压制并经过恢复延迟 | +2/tick |

这些是平衡草案。玩家崩势通常应短于普通怪物（可先测试普通敌人约 12–20 tick）；Boss 可以采用专属规则。**崩势是追击机会，不是自动死亡判决**。普通生命伤害依然持续有效，不要求敌人先崩势才能掉血。

### 5.4 高速追击与抗无限连

```text
崩势 → 切上 → 空中轻击 → 空中返刃 → 追击斩 / SA → 落地
```

一次有效追击链分配初始 **3 点控制预算**：空中普通攻击消耗 1 点，高级追踪或再次击飞消耗更多。耗尽后目标进入短暂抗浮空保护。连招伤害衰减与目标抗控制状态不能被 SA 或 Burst 轻易重置。保护主要限制连续控制，不应禁止全部普通攻击。
