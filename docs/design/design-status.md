## 继承的架构基线，细节待验证

原稿的机制和细节不因模块摘要或历史归档自动废止。本轮发现此前过度压缩，已恢复轻重/居合/挑飞、方向派生、SA 变体与图修改器、取消规则、表现/网络/注册/验收细节。逐项状态见[原稿保留审计](reviews/baseline-retention.md)。未明确改动的内容继续作为继承提案，不等于已实现或所有参数已确认。

统一 ActionRuntime、条件动作图、Gameplay/Presentation 分离、服务端权威与客户端预测、Combat Style 组合扩展，是原讨论形成的设计基线。不能将示例代码或“冻结”用语等同于已实现规范。

日本刀与居合作为首套内容，长枪作为第二武器验证，是原稿内容规划。具体动作和阶段范围尚未定稿。架势、控制预算、伤害衰减与骨骼动画也需验证，不要求全部武器使用相同机制。

## 本次审核与原型状态

用户已接受[综合战斗方案](proposals/combat-recommendation-v1.md)作为原型基线。首轮采用单模式槽、常态 SA 不统一付气、模式内暂停积攒、保留已积攒气；纳刀重整、基础终结和 SA 主动变体并存。旧脱战衰减仅作备选，早期“只少量改图”不限制能力范围。

当前任务是完善资料并提交推送，用户审核后再委派原型。阅读[审核入口](review.md)、[原型任务说明](proposals/prototype-spec-v1.md)和[实施准备](proposals/implementation-readiness-v1.md)。尚未启动战斗代码、正式资产制作或原型委派。

| 状态 | 当前内容 |
| --- | --- |
| 已接受的原型基线 | 原稿剑术骨架、纳刀收益、SA 附加/主动路线、气/模式循环、防御与有限控制 |
| 原型比较布局 | 左轻、右重、Shift 防御、Alt 回避、中键锁敌、R 纳刀、B 模式；接受作为试验起点，不是最终人体工学结论 |
| 新审核候选 | V 通用主动特殊入口；F 临时原版交互切换；节点/转换表、数据与分阶段交付说明 |
| 技术审核候选 | Blender 源资源、静态 OBJ/PNG、版本化动画/挂点与独立权威轨迹；共用角色骨架、身体扭转与简单遮罩/过渡 |
| 需要原型确定 | 默认键/舒适度、具体窗口/成本/收益、模式时长和气权重、轨迹/动画对齐与旧版渲染兼容 |
| 继续细化 | 多 SA 装配/互斥、更多形态、死亡/维度资源保留、公开 API 与后续内容 |

次元斩/闪移是具体样例，不要求每项 SA 变形或每种武器同一动作。瞬移不默认穿墙、无敌或自动背后追踪。常态 SA 不全锁在爆气后，普通实体不强制具备完整架势/动作图。

持刀默认启用稳定战斗映射，纳刀与未锁敌仍可战斗，普通物品恢复原版操作。F 交互切换是本次补齐候选，需检验原版潜行/开箱与输入清理；不凭准星环境自动改键义，不绕过权威恢复。

Blender 与资源方案见[模型资源](modules/assets.md)，全身扭转需共用骨架及几何绑定；单块躯干整体转动不能代替胸腰分段。导出器、模型加载和播放器目前不存在，未验证资源格式支持，也未冻结 API。

## 仓库实现与工具链

项目名及 mod ID 为 Clashweave / clashweave，原暂定名 Project KATANA；中文名“势织”未确认。当前只有 Forge 初始化骨架，尚无攻击流、SA、爆气、锁敌相机或战斗网络实现。

Java 8 为目标代码工具链；Gradle 运行 Java 25，反编译工具使用 Java 17。既有构建记录见[根 README](../../README.md)，不能作为战斗功能验收。
