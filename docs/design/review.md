# 本轮设计审核入口

本页记录已通过审核的基线与候选（审核通过：2026-10-09）。原型第一阶段为技术探针，入口见[执行者入口](executor-entry.md)。当前仅有 Forge 骨架，尚无战斗实现、正式模型或动画播放器。

## 已接受的基线

1. 独立 Minecraft 1.7.10 框架，首套内容保留原稿日本刀的纳刀/居合、轻重、切上、有限空中追击和特殊能力。
2. 同类武器主体剑术相近，SA 增加效果和主动特殊路线；多个能力与上下文变体继续由统一动作图支持。
3. 纳刀以准备风险换下一次居合的间合/时机机会，不免费取消后摇或恢复架势。
4. 气来自有效攻击、格挡和受伤，爆气作为临时模式入口。原型使用单槽，常态 SA 不统一付气，模式期间暂停积攒下一次资格，先保留已积攒气。
5. 普通攻防和有限控制在无气时成立。终结融入攻击流，不强制新增大招按钮或击杀演出。
6. 双视角支持、锁敌、鼠标观察优先、弱跟随及可选自动第三人称。相机不改变命中或动作结果。

完整理由与取舍见[综合方案](proposals/combat-recommendation-v1.md)。接受基线不等于具体数值、样例效果和接口已通过验证。

## 建议审核顺序

先检查本页基线与候选，再读原型说明的输入/动作/验收，最后读资源制作的骨架、导出与兼容部分。技术章节已有详细原稿时，查看负责模块即可；需要追溯时再读[完整原稿](clashweave-v1.0.md)与[保留审计](reviews/baseline-retention.md)。

## 委派时的边界

设计审核已通过，先做技术探针 S1–S5，全部有结论并经用户审核后再进入 P0。执行者以审核结论和负责模块为准；未被明确调整的原稿仍继承。阶段后置不表示删除动作、SA 变体、第二武器、高级动画或兼容规划。

公开 API、最终数值和全部美术不在此时冻结。执行者遇到多个同等候选，应报告选择及验证证据；不得以“简化原型”为由把完整攻击流退化为左键连点加单一外部技能。
