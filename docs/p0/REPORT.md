构建实际执行 **15 项 JUnit**，没有 NO-SOURCE；Spotless、Checkstyle 和 build 成功。覆盖过期派生不偷换、同目标同段一次命中、全排列同 tick 冻结交换命中、最近有效缓冲、非法入口/未实现节点拒绝、GUI 清缓冲保留恢复/账本、反击窗过期不转空闲招、双时钟与严格纳秒边界、会话/重放/未来/过期输入、批量位移及观察者序列化不改变持有者消息、迟到/中断/过时空闲实例拒绝及36字节原实例往返/旧包拒绝。专用服务器 [server-28](evidence/server-28/summary.json) **18 项断言**，exit=0，客户端/OpenGL 类加载0。联网所选场景须同时有 exit=0 与 COMPLETE；仅退出码0不作成功证据。

## 降级、设计影响与未完成验收

按用户范围，缩小P0保留原稿完整攻击图的已列节点；light_2重击切上、Alt/V/B、SA、模式与追击明确拒绝，没有偷换招。第5节纳刀态HEAVY非法，先左键居合或拔刀后重击。原稿未明确时序列在 katana.json 的 missingOriginalTiming，反击窗暂8tick在combat.cfg，所有动作/防御/预算平衡数值可配置；没有冻结公开API。

原型第6节“普通/精准格挡、架势恢复、控制预算按原稿基线起步”比用户本次缩小P0包含的防御路线更广；本轮实现普通减伤、精准免伤与可配置反击入口窗口，没有架势槽/崩势/受击硬直/浮空预算。建议将该段补注缩小P0的边界，把完整控制验收留在明确新增控制机制时，不能宣称当前已实现其全部要求。已冻结双方合法接触排序后可交换命中；遍历全排列JUnit通过，真实多人同tick致死交换未独立脚本验证。

原型1.2位移条件的灵敏度实测推翻“预算可识别轻度短程超速”的任何隐含推论；建议明确区分异常大位移校验和精细作弊检测，余量内1.2/1.5倍加速、END之间离开又返回仍不可观测。第7节可见路径和权威轨迹当前按同动作有效期/角度插值，但第一人称表现不是权威刀刃每个采样点的严格映射，世界坐标轨迹同屏叠加尚未验证。

原型1.2第5条的纳刀状态静态位置可检查，完整插入全过程和抓握有降级，详见逐张判读，不降低旧截图审核标准。模块“原稿细节保留”完整保留。本报告中的建议是待审修改建议，没有直接改写模块规则冒充审核。
