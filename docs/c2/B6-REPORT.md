# B6 第二轮身体动画欠账

## 1 第一人称双臂(C2a-2)

**已验证**:持刀战斗态下第一人称画出双臂和刀,与第三人称同一套姿态(烘焙轨迹、`CombatBiped` 肘关节、刀按 `swordMatrix`);身体在世界里固定,镜头俯仰与镜头相对身体朝向(限制在 45°内)都会作用在手臂上。`--souls-view --pose-verify 90 --first-person` 拍到 `iai`、`light_1` 各 6 帧(标签 `b6fp-1`),截图见 `b6-shots/`。JUnit 全过。

**未验证**:未持刀战斗态之外的第一人称移动(走、跑、潜行、跳)、盔甲、骑乘、游泳;镜头朝上时的手臂位置;非 70° 视野。

**已知问题**:手臂按真实身体位置画,平视时大部分在画面下沿,不如原版手臂"抬在眼前"醒目;若观感不好,可加一个第一人称专用的抬升偏移。

**性能**:未做 A/B(按口径)。第一人称每帧复用预分配的 `CombatBiped`,无新分配路径,未专门写分配测试。

## 2 战斗态走路躯干扭转与持刀走姿

做法:战斗待机(站姿)走路时,躯干随步伐扭转取移动层扭转的一半(`CombatBiped.STANCE_TWIST`),刀、双手、手臂方向随躯干一起绕腰转(`Pose.twistTo`,同一帧多个模型取同一值,幂等),腿不受影响。持刀未战斗(已拔刀、空闲)不再回到原版持物姿势,改用同一个预备站姿(`PoseDriver` 去掉 `engaged` 条件),腿照常走。

**已验证**:`--move-verify 45/90 --move-mode stance`(`b6st-45`、`b6st-90`、`b6st2-90`):走路中躯干在帧间可见转动,刀与双手没有脱开;持刀未战斗的走路画面(`drawnwalk`)与预备站姿一致。JUnit 含 `PoseTwistTest`(幂等、长度保持、四元数归一、可还原)。

**未验证**:0/135/180 视角;跑步、潜行、跳跃时的站姿扭转;扭转系数 0.5 为经验值,待观感反馈;持刀未战斗与上一个版本的原版持物姿势相比,是用户可见的行为变化(现在一拔刀就是预备站姿)。
