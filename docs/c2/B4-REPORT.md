# B4:`ModelBiped` 系怪物(第一批)

状态:**草稿,等待审核**。日期:2026-10-13。基线:`work`(含 B3),分支 `b2/locomotion`。

## 1 结论

- 僵尸、骷髅、僵尸猪人(渲染器用 `ModelZombie`/`ModelSkeleton`/`ModelBiped`,且未穿盔甲)现在走 B2 的移动层:腿屈膝迈步、躯干随步伐扭转与前倾、头反向补偿、肘膝带关节,全部经过帧率无关的平滑。
- 怪物自己的姿势保持不变:僵尸与猪人双臂前伸由原模型决定(这两条手臂保持原版),骷髅拉弓时持弓姿势保留,挥击保留;其余(躯干、腿)由我们驱动。
- 穿了盔甲的怪物仍按原模型渲染:盔甲模型只按原版角度摆动,不会跟随我们的躯干与腿,贸然叠加会错位。

## 2 实现

| 部分 | 内容 |
|---|---|
| `LimbSlicer` | 通用肢体切分:读取怪物模型自带的方块,在关节处切成上下两段,每个新面的贴图坐标从它所切自的原面推出(不假设皮肤布局,所以 4 px 的僵尸肢体、2 px 的骷髅肢体、镜像的左臂都适用);关节处加八边形棱柱填外侧缺口。思路参考 Mo' Bends 的 `BoxMutator`(MIT),为本代码库重写。 |
| `MobBiped` | 替身模型:部件用原模型自己的(已被切开),原模型仍先摆姿势,再叠上身体骨架的目标;原模型的标志(持物、拉弓、潜行、挥击进度)在两者间同步。 |
| `MobBodies` | `RenderLivingEvent.Pre`:第一次见到某个 `RenderBiped` 时把它的模型换成替身;只处理上述三种模型类,其他模组的自定义模型类、村民、蜘蛛等不动;切分失败则保持原样;穿盔甲的实体换回原模型。 |
| `BipedChannels` | 从 `CombatBiped` 抽出读取原版姿态/写回通道的代码,玩家与怪物共用;起始枢轴由模型自己的值给出。 |

## 3 验证

单元测试:JUnit 全过。`LimbSlicerTest`(切开后上段不越过关节、下段从关节量起、贴图坐标在皮肤内、棱柱 14 个面、非单个高方块的部件不切;4 px 与骷髅 2 px 肢体)、`MobBodiesTest`(只认原版模型类与僵尸村民,模组子类被跳过;`MobBiped.setRotationAngles` 每百万次调用分配 0 字节)、`LocomotionTest`(新增步态与忙碌手臂肘弯的断言)。

实机(客户端临时生成的怪物,手动位移并设置摆动幅度;`dual.py --move-verify <角度> --move-mode mobs`):

| 视角 | 标签 | 场景 |
|---|---|---|
| 90° | `b4v-mobs-90`、`b4v-g-90`、`b4v-g-90b` | 僵尸、骷髅、猪人(持金剑)、穿铁甲僵尸/骷髅(整套)、持弓骷髅、儿童僵尸、水中、鸡骑士、蜘蛛骑士、模组风格子类模型、僵尸村民 |
| 0° / 45° / 135° / 180° | `b4v-mobs-0/45/135/180` | 同上(未含后加的整套盔甲、僵尸村民) |

结论:各视角下躯干与腿、手臂与肩没有错位,肘/膝连续;持弓、持剑姿势保留;鸡骑士、蜘蛛骑士是坐姿;水中是游泳姿;儿童僵尸比例正常;**模组风格的 `ModelZombie` 子类被跳过,按它自己的模型渲染**;穿铁盔甲(含整套)的僵尸、骷髅,盔甲随躯干与腿跟随(盔甲模型换成了与玩家盔甲同一个整块跟随的类)。

真实服务端 AI 驱动的怪物(`--move-mode walkers`,标签 `b4v-walkers-90`):服务端生成的僵尸、骷髅、猪人走向玩家,环绕拍摄最近的一只,31 张,走动正常,没有异常。

战斗回归 `b4-pose-90-1`(接管之后第一次):玩家持刀姿势正常、真实服务端僵尸正常显示,日志没有新异常。

性能:按当前口径只看代码层面,不做 A/B。代码层面的保护:怪物每帧零分配(上述测试);关节棱柱在关节几乎伸直时(<约 3.4°)不绘制,走路和站立时一半以上的帧可省掉;切分在首次见到渲染器时一次完成,显示列表只编译一次;`BodyRigs` 查表无装箱,过期实体的骨架每 120 秒整体丢弃。实测数据只有一次未完成的对照,**不作结论使用**:40 只僵尸、接管开/关各 3 轮,平均帧时间约 0.56–0.60 ms 对 0.88–1.06 ms(无帧率上限,约每只僵尸 +0.01 ms);关节棱柱隐藏优化之后的那一组被用户叫停,未测。性能优化与正式对比留到最后。

未验证:其他模组的真实怪物(只用模组风格的替身模型类验证了"被跳过");皮革盔甲、金/锁链盔甲的外观(只试了铁);猪人拿其他物品;多只怪物重叠时的深度排序;怪物受击/死亡动画(死亡翻倒由渲染器完成,未专门看);战斗回归只做了接管后第一轮。

## 4 已知问题

1. 僵尸/猪人/僵尸村民双臂前伸由原模型决定,我们只加了轻微左右摇晃和肘弯。
2. 非这四类模型的怪物不动(其他模组怪物、村民、四足、苦力怕、蜘蛛、末影人等,见 B5 计划)。
3. 穿盔甲的怪物,盔甲是整块跟随,弯曲的膝/肘处盔甲仍是直的(与玩家一致)。
4. 怪物步态数值(`Gait.ZOMBIE`、`Gait.SKELETON`)是首版经验值,待观感反馈。
